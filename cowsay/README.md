# cowsay

Configurable talking cow that displays a message.

| Field | Value |
|-------|-------|
| **Type** | Easy |
| **Score** | 100 |
| **Reference** | JavaScript/Node.js |

## Prerequisites

- Node.js 18+

## Build

```bash
cd cowsay/source && npm install --ignore-scripts
```

## Run

```bash
node cowsay/source/cli.js "Hello, world!"
```
